# Triage

## Project Tracker

Follow `/home/unbalanced/.agents/instructions/project-artifacts.md`. Read
`.agents/issue-tracker.md`, `.agents/triage-labels.md`, `.agents/domain.md`,
glossaries, ADRs, and `.agents/out-of-scope/` before posting or changing state.
If tracker config is missing, run or recommend `setup-matt-pocock-skills`.

Every issue or comment posted during triage must start with:

```markdown
> *This was generated by AI during triage.*
```

## States

- Category roles: `bug`, `enhancement`.
- `needs-triage`: not yet evaluated.
- `needs-info`: blocked on reporter/user detail.
- `ready-for-agent`: enough context, acceptance criteria, and verification for an AFK agent.
- `ready-for-human`: product, design, access, or judgment still required.
- `wontfix`: duplicate, out of scope, invalid, or not worth doing now.

Every triaged issue should carry exactly one category role and one state role.
Use the tracker-specific label mapping from `.agents/triage-labels.md`.

## Workflow

1. Read the full issue, comments, labels, linked PRs, and previous triage notes.
2. Inspect relevant code and docs. For bugs, attempt reproduction before asking product questions.
3. Summarize current understanding, likely area, and missing facts.
4. Recommend one state with reasoning.
5. If needed, run `grill-with-docs` to resolve missing decisions.
6. Apply outcome through the configured tracker:
   - `ready-for-agent`: post an agent brief using `references/AGENT-BRIEF.md`.
   - `ready-for-human`: same brief shape, with why delegation is unsafe.
   - `needs-info`: post specific questions.
   - `wontfix` enhancement: update `.agents/out-of-scope/` using
     `references/OUT-OF-SCOPE.md`, then close or mark done.
   - `wontfix` bug: explain and close/mark done.

## Ready-for-Agent Checklist

- Expected behavior and current behavior are clear.
- Repro steps or implementation goal are concrete.
- Relevant files or search terms are included.
- Acceptance criteria are testable.
- Verification commands are listed.
- Dependencies and out-of-scope items are explicit.

## Attention Buckets

When asked what needs attention, show oldest first:

- Unlabeled or uncategorized.
- `needs-triage`.
- `needs-info` with reporter/user activity since the last triage note.
