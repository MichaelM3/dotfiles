# GLOSSARY.md Format

```markdown
# <Topic> Glossary

One or two sentences describing the topic.

## Terms

**Term**:
One or two sentences defining the concept.
_Avoid_: loose synonym, misleading synonym
```

## Rules

- Add a term only when the user understands it.
- Pick one canonical term when several words exist.
- Keep definitions tight.
- Use glossary terms inside later definitions.
- Group under headings when natural clusters emerge.
- Flag ambiguities explicitly.
- Revise stale definitions in place.
