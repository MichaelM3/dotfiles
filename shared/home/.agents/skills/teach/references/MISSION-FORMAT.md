# MISSION.md Format

```markdown
# Mission: <Topic>

## Why
One to three sentences describing the real-world outcome.

## Success Looks Like
- Observable capability
- Observable capability

## Constraints
- Time, budget, prior knowledge, preferences, or access limits

## Out Of Scope
- Adjacent topics not being pursued now
```

## Rules

- One mission per workspace.
- Concrete over abstract.
- Push back on vague goals before writing.
- Revise when the user's real goal changes.
- Keep it short.
