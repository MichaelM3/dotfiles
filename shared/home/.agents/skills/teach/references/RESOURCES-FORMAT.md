# RESOURCES.md Format

```markdown
# <Topic> Resources

## Knowledge

- [Title](https://example.com)
  What it covers. Use for: specific learning need.

## Wisdom

- [Community](https://example.com)
  Why it is high-signal. Use for: real-world feedback need.

## Gaps

- Missing source for ...
```

## Rules

- Prefer primary sources, recognized experts, peer-reviewed work, and strongly
  moderated communities.
- Annotate every link.
- Group by Knowledge and Wisdom.
- Record source gaps explicitly.
- Prune shallow or off-mission resources.
- Note community preferences if the user opts out.
