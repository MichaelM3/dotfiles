# Grilling

Interview until the plan is precise. Walk the decision tree in dependency
order. Ask one question at a time and wait for feedback before continuing.

For each question:

- include your recommended answer
- explain the trade-off briefly
- inspect code instead of asking when code can answer

Do not write docs or code unless the invoking skill says to do so.
